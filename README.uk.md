# Кооператив для PvZ Fusion

Мод для **Fusion 4.1, Windows IL2CPP**: двоє гравців проходять звичайні рівні на спільному полі.

Спільні сонечки, окремий вибір звичайної та дорожчої копій картки, стрілочки посадки, перегляд колоди друга з відкатами, ручне введення IP і порту.

Кооператив допрацьовано за допомогою **OpenAI Codex**.

**[ГОТОВА ГРА З КООПЕРАТИВОМ — розпакувати й запустити](https://github.com/dwdwqdwq/pvz-fusion-coop/releases/latest/download/PvZ-Fusion-4.1-with-Coop-Mod-v0.11.0.zip)**

**[ЛИШЕ МОД — якщо Fusion 4.1 уже встановлений](https://github.com/dwdwqdwq/pvz-fusion-coop/releases/latest/download/PvZ-Fusion-Coop-0.11.0.zip)**

## Встановлення

### Готова гра з кооперативом

Повністю розпакуйте великий архів і відкрийте **Start Co-op.cmd**. Fusion **4.1**, завантажувач і кооперативний мод **v0.11.0** уже включені. Окремо встановлювати гру чи копіювати DLL не потрібно.

### Лише мод — якщо гра вже є

Для меншого архіву мода потрібна власна сумісна гра Fusion 4.1 зі встановленим BepInEx IL2CPP. Один раз запустіть її, щоб створилися файли `interop`.

Закрийте гру й розпакуйте ZIP релізу в її папку. Мод і його керована залежність потраплять у `BepInEx/plugins/PvZCoop/`. До меншого архіву «лише мод» повна гра, завантажувач BepInEx та збереження не входять.

## Мова

У головному меню натисніть **LANGUAGE** праворуч угорі. Виберіть **Українська** або **English**, потім перезапустіть гру. Вибір зберігається. Публічна версія починає з англійської; у кожного гравця може бути своя мова.

Українська має перемальовані меню й адаптований шрифт. У великих довідкових текстах є автоматичний переклад; окремі формулювання ще потребують редагування.

## Гра вдвох

1. Підключіться до однієї мережі. Для гри на відстані можна використати **Radmin VPN** або **ZeroTier One**: обидва гравці мають приєднатися до однієї віртуальної мережі.
2. У меню **КООП** ведучий створює гру. Звичайний порт — `27650`.
3. Друг вводить локальну IP-адресу ведучого й той самий порт та приєднується. Для гри через VPN вводьте **VPN IPv4-адресу ведучого**, а не його звичайну Wi-Fi-адресу.
4. Ведучий обирає звичайний рівень. Обидва вибирають картки й натискають **ГОТОВО**.

Steam для LAN не потрібен. Автоматичного інтернет-пошуку гравців і сервера-посередника немає. На обох ПК рекомендовано однакову версію мода.

## Вихідний код

Збірка: `./build.ps1 -GameDir 'D:/Games/Fusion-4.1'`. Потрібен .NET SDK 8 або новіший і власні ігрові бібліотеки. Команда створює DLL, але не встановлює її в гру.

Відомості про авторство стороннього коду та матеріалів — у [README](README.md#credits-and-scope). Цей неофіційний мод не надає прав на саму гру чи чужі матеріали.
