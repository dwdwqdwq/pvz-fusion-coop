# PvZ Fusion Co-op

Неофіційний мод кооперативного проходження **PvZ Fusion 4.1 для Windows (IL2CPP)**. Захищайте спільне поле з друзями. Розроблено за допомогою OpenAI Codex.

[English](README.md) · [Завантажити перевірений P0-патч](https://github.com/dwdwqdwq/pvz-fusion-coop/releases/tag/coop-p0-2026-11-23)

## Поточна збірка: P0 review — 23 листопада 2026

Це **оновлення кооперативного мода**, а не нова версія Fusion. Внутрішній номер `0.12.13`, протокол `fusion41-coop-p0-atomic-v2`. Самого номера недостатньо: звіряйте хеш DLL нижче.

- Хост підтверджує смерть зомбі; старі пакети не повинні відновлювати загиблі сутності.
- Посадка й спільне сонце обробляються як одна операція: захист від повторних запитів, закінчення очікування та явна обробка помилок.
- Перевірено сценарії рукавички, дозрівання мін, Чомпера, вибухів, HP/броні, статусних ефектів, паузи, рестарту й нагород кампанії.
- Перегляд карт друга з відкатами, позначки посадки та вибір української/англійської мови.

## Встановлення / оновлення

1. Потрібна Fusion 4.1 з робочим BepInEx IL2CPP та наявними залежностями кооперативу, зокрема `Steamworks.NET.dll`. Це **невеликий патч**, а не повна гра чи комплект для першого встановлення завантажувача модів.
2. Закрийте гру та збережіть копію `BepInEx/plugins/PvZCoop/PvZCoop.dll`.
3. Завантажте `PvZ-Fusion-Coop-P0-review-2026-11-23.zip` з релізу й розпакуйте в папку гри із заміною цієї DLL. Збережень і налаштувань мови в архіві немає.
4. **У всіх гравців має бути однакова DLL. Старі релізи несумісні з цим протоколом.**

SHA-256 DLL:
```text
c1d979503b688ae8ef5657dd7232f1d7aae503831eed54cad23c257c0acee68a
```

## Як грати

1. Підключіться до однієї локальної мережі або спільної віртуальної мережі **Radmin VPN / ZeroTier One**, якщо граєте на відстані. Ці програми встановлюються окремо.
2. Відкрийте КООП. Хост створює кімнату й обирає TCP-порт, типово `27650`.
3. Гості вписують LAN/VPN IPv4-адресу хоста та той самий порт. Дозвольте мережеве підключення гри у відповідній приватній мережі.
4. Хост обирає звичайний рівень, усі обирають карти й натискають ГОТОВО.

Автоматичного пошуку кімнат або інтернет-реле немає. Відновлення після повного закриття TCP-з'єднання цим релізом не перевірене.

## Мова

У головному меню оберіть **LANGUAGE → English / Українська**, потім перезапустіть гру. Або встановіть `[Language] Interface = en` чи `uk` у `BepInEx/config/pvzfusion.coop.cfg`, поки гра закрита. Мова кожного гравця налаштовується окремо.

## Що перевірено

**17 парних прогонів справжньої гри у12 сценаріях**: дві ізольовані копії на одному ПК, звичайний газон, складність1. Перевірки TCP включали затримки200/500/800мс, коливання затримки, повтори/втрату ігрових повідомлень та короткі зупинки потоку. Порівнювали справжні ID, HP/броню, таймери, позиції й кліпи анімації; навмисно спотворені вимірювання відхилено.

Це **не гарантія відсутності всіх багів** і не повне проходження кампанії. Усі633 рослини, чотирьох гравців та два фізичні ПК через інтернет не перевіряли. Підтримка чотирьох експериментальна. Втрата ігрового повідомлення не дорівнює втраті IP-пакета. [Докладніше про перевірки](docs/VERIFICATION.md).
