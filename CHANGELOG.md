# Changes

## 0.11.0

- Public build defaults to the original English interface.
- Main-menu language selector supports English and Ukrainian; settings persist and apply after restart.
- The Ukrainian menu artwork and font from 0.10.2 are active only in Ukrainian sessions.
- English card hints and IP input placeholders no longer leak hard-coded Ukrainian text.
- Portable build script takes the local game path instead of depending on the author's workspace layout.
